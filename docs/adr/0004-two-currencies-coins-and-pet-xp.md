# Coins are spendable in the parent reward shop; pet progress uses separate, non-spendable XP

The retention bet is an instant, parent-free loop (pet reacts, level grows) alongside the slower parent reward loop. If pet items cost coins the child must choose between the pet and a real reward, and the instant loop competes with the parent's. So completions grant both coins and XP; XP only drives pet level and is never traded. Coin amounts are fixed (10 per chore, 20 daily bonus, streak bonuses) and not parent-tunable, to avoid the "250 points for one reward" failure seen in competitors. Completions count immediately; parents reject after the fact rather than approve up front, except photo-proof chores.
